Módulo Gratuito 01

Progressão Aritmética (P.A.)

1. O que é e Razão (r)

É toda sequência numérica em que cada termo, a partir do segundo, é igual ao anterior somado a uma constante chamada razão (r).

r = a₂ - a₁ = a₃ - a₂

• r > 0: Crescente (2, 5, 8...)
• r < 0: Decrescente (10, 7, 4...)
• r = 0: Constante (5, 5, 5...)

2. Termo Geral (aₙ)

Permite descobrir qualquer termo da sequência sem precisar escrever todos os anteriores um por um.

aₙ = a₁ + (n - 1) · r

Onde a₁ é o primeiro termo, n é a posição desejada e r é a razão.

3. Soma dos Termos (Sₙ)

Soma os n primeiros termos somando os extremos e multiplicando pela metade da quantidade de termos.

Sₙ = ((a₁ + aₙ) · n) / 2

Propriedade útil: O termo do meio é sempre a média aritmética dos vizinhos: a₂ = (a₁ + a₃) / 2.

Módulo Gratuito 02

Média, Mediana e Moda

1. Média Simples (x̄)

Soma todos os valores do conjunto e divide pela quantidade total de elementos.

x̄ = (x₁ + x₂ + ... + xₙ) / n

2. Média Ponderada

Multiplica cada valor pelo seu respectivo peso e divide pela soma dos pesos.

Mp = Σ(valor · peso) / Σ(pesos)

3. Mediana (Md)

Primeiro ordene os números (Rol)!
• Ímpar: é o termo central.
• Par: média dos 2 termos centrais.

4. Moda (Mo)

É o valor que aparece com maior frequência. Pode ser amodal (nenhum repete), unimodal ou bimodal.
